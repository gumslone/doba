Die eigene Buchungsseite für Ihr Haus. Ohne Provision.

Doba ist eine vollständige Buchungsmaschine mit Website für unabhängige Hotels, Pensionen und Ferienwohnungen. Gäste buchen direkt bei Ihnen, das Geld geht an Sie, und die Gästekartei bleibt Ihre.

Im Browser ausprobieren In zehn Minuten installieren Quellcode ansehen →

Keine Anmeldung, keine Kreditkarte, kein „Vertrieb kontaktieren“. Software, die Sie herunterladen und besitzen.

Was die Portale kosten

Rechnen Sie nach, was Sie an Provision zahlen

Stellen Sie die Regler auf Ihr Haus ein. Die Rechnung steht vollständig darunter — eine Zahl, die man nicht nachprüfen kann, ist Werbung.

Provision pro Jahr
—
Bucht jeder dritte dieser Gäste direkt, behalten Sie
—

Zimmer × 365 × Auslastung × Portalanteil = Nächte über Portale, × Preis × Provision.

Portale bringen Gäste, die Sie sonst nie erreicht hätten, und Doba ersetzt sie nicht. Es sorgt dafür, dass die Gäste, die Ihren Namen schon kennen — Stammgäste, Leute, die Sie nach dem Portal gegoogelt haben, Bekannte von Bekannten — in zwei Minuten direkt buchen können, statt Sie jedes Mal 15 % zu kosten.

Eine echte Buchungsmaschine

Verfügbarkeit in Echtzeit, Saisons und Ratenpläne, Mindestaufenthalte, Reservierung während der Zahlung — und ein Schutz vor Doppelbuchungen, der bei jeder Änderung getestet wird.

Zahlungen auf Ihr Konto

Stripe, PayPal, LiqPay, Überweisung oder Zahlung vor Ort. Anzahlung jetzt, Rest später, Kurtaxe als eigene Zeile, Erstattungen und Gutschriften.

🌐

Eine Website, die gefunden wird

Ihre eigene Seite in sechs Sprachen, mit sauberem technischem SEO: hreflang, strukturierte Daten, Sitemap, schnelle Seiten. Für „Hotel in Ihrem Ort“ gefunden zu werden ist der Zweck.

Zimmer und Ferienwohnungen

Hotelzimmer und Wohnungen nebeneinander verkaufen: Endreinigung einmal pro Aufenthalt, Mindestnächte, Schlaf- und Badezimmer, zwei Einheiten in einer Buchung.

Installation

Drei Wege, alle enden beim selben Einrichtungsassistenten

Der Assistent fragt nach dem Namen Ihres Hauses, Ihren Zimmern und Preisen — danach ist der Kalender live. Eine Kommandozeile brauchen Sie nicht.

Ohne Vorkenntnisse

Eine Datei hochladen

  1. doba-installer.php aus dem neuesten Release herunterladen.
  2. Per FTP auf Ihren Webspace laden.
  3. Im Browser öffnen und den Schritten folgen.

Installer herunterladen

Benötigt Webhosting mit PHP 8.4. Bei den meisten Anbietern lässt sich die PHP-Version im Kundenmenü wählen.

Heimserver, NAS oder VPS

Docker

  1. Diesen einen Befehl ausführen.
  2. Die Adresse im Browser öffnen.
  3. Ein Update ist später nur ein neueres Image.
docker run -d -p 8080:80 \
  -v doba-data:/data \
  -e DOBA_URL=http://localhost:8080 \
  ghcr.io/gumslone/doba

Details zu Docker

Läuft auch auf Raspberry Pi und Synology.

Mit Shell-Zugang

Eine Zeile

  1. Auf Ihrem Server einfügen.
  2. Den Webserver auf den Ordner public zeigen lassen.

Ehrlich zum Stand

Jung, getestet — und auf der Suche nach den ersten Häusern

Doba ist neu. Über 600 automatische Tests auf zwei Datenbanken sichern es ab, aber noch läuft kein Hotel produktiv darauf — genau deshalb ist jede Version als Vorabversion gekennzeichnet.

Wenn Sie ein kleines Haus führen und zu den Ersten gehören möchten, bekommen Sie die volle Aufmerksamkeit des Entwicklers: Sagen Sie, was unklar war, und es wird behoben. Auch Webagenturen sind willkommen — MIT-lizenziert, frei gestaltbar, für Kunden installierbar. Zur Seite für Agenturen.
