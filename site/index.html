Your hotel's own booking site. No commission.

Doba is a complete booking engine and website for independent hotels, guesthouses and holiday apartments. Guests book with you directly, the money goes to you, and the guest list stays yours.

Install

Three ways in, all ending at the same setup wizard

The wizard asks for your hotel's name, your rooms and your prices, and the calendar is live when it finishes. No command line needed.

No technical knowledge

Upload one file

  1. Download doba-installer.php from the latest release.
  2. Upload it to your web hosting with FTP.
  3. Open it in your browser and follow the steps.

Download the installer

Needs web hosting with PHP 8.4. Most hosts let you pick the PHP version in their control panel.

Home server, NAS or VPS

Docker

  1. Run this one command.
  2. Open the address in your browser.
  3. Updating later is pulling a newer image.
docker run -d -p 8080:80 \
  -v doba-data:/data \
  -e DOBA_URL=http://localhost:8080 \
  ghcr.io/gumslone/doba

Docker details

Works on a Raspberry Pi and a Synology too.

With a shell

One line

  1. Paste this on your server.
  2. Point your web server at the public folder.
  3. Open the site — the wizard takes over.
curl -fsSL \
  https://raw.githubusercontent.com/gumslone/doba/main/scripts/install.sh \
  | bash

Honest about where it is

Young, tested, and looking for its first hotels

Doba is new. It is covered by more than 600 automated tests on two databases, and no hotel has run on it in production yet — every release is marked pre-release for exactly that reason.

If you run a small house and are willing to be one of the first, you get the maintainer's full attention: tell us what confused you and it gets fixed. Web agencies are welcome too — it is MIT-licensed, re-themeable, and yours to install for clients.
